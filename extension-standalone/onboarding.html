به PechPech خوش آمدید 👋

افزونه‌ای که جلسات آنلاین شما را ضبط می‌کند و بدون هیچ یادداشتی، صورت‌جلسه فارسی آماده تحویل می‌دهد. این نسخه هیچ سرور محلی نیاز ندارد — همه‌چیز مستقیماً از داخل مرورگر شما انجام می‌شود.

🎙
ضبط هوشمند جلسه
صدای تب مرورگر (Google Meet، Teams، Zoom Web) و میکروفون شما را همزمان ضبط و ترکیب می‌کند. هیچ نرم‌افزار جانبی لازم نیست.
💾
ذخیره‌سازی محلی در مرورگر
ضبط‌ها مستقیماً در حافظه مرورگر شما (IndexedDB) ذخیره می‌شوند — بدون فایل روی دیسک و بدون سرور واسط.
📝
تبدیل گفتار به متن و صورت‌جلسه
صدا مستقیماً به سرویس STT (OpenAI Whisper یا Gemini) ارسال می‌شود، سپس یک مدل زبانی خلاصه، تصمیمات و اقدامات را به فارسی می‌نویسد.

چطور کار می‌کند؟

افزونه Chrome
صدای جلسه را ضبط و مستقیماً در حافظه مرورگر شما (IndexedDB) ذخیره می‌کند — هیچ سرور یا فایل روی دیسک درگیر نیست.
۲
Whisper STT
صدا مستقیماً از افزونه به OpenAI یا Gemini ارسال می‌شود و به متن فارسی تبدیل می‌گردد. کلید API را در تنظیمات وارد کنید.
۳
مدل زبانی (LLM)
OpenAI یا Gemini (پیشنهادی)، یا هر API سازگار با OpenAI. متن جلسه را تحلیل و صورت‌جلسه می‌نویسد.

راه‌اندازی اولیه

فقط کافی است یک کلید API برای STT و یک کلید برای LLM وارد کنید — نیازی به نصب یا اجرای هیچ سروری نیست.

۱
یک کلید API تهیه کنید
از platform.openai.com یا aistudio.google.com یک کلید API رایگان/پولی بگیرید.
۲
تنظیمات افزونه را باز کنید
روی دکمه «باز کردن تنظیمات افزونه» زیر بزنید، سرویس STT و LLM را انتخاب کرده و کلید API را وارد کنید.
۳
ذخیره کنید
روی «ذخیره تنظیمات» بزنید. آماده‌اید — به مرحله بعد بروید تا اتصال را بررسی کنیم.

هنوز کلیدی وارد نکرده‌اید؟
روی «باز کردن تنظیمات افزونه» بزنید، کلید STT و LLM را وارد و ذخیره کنید، سپس دکمه «بررسی مجدد» را بزنید.
🎉

آماده‌اید!

PechPech نصب شده و منتظر اولین جلسه شماست.

🎙 در جلسه بعدی، تب Google Meet یا Teams را باز کنید، روی آیکون PechPech در نوار Chrome کلیک کنید و شروع ضبط را بزنید.
⏹ در پایان جلسه توقف و ذخیره را بزنید. فایل صوتی مستقیماً در همین مرورگر ذخیره می‌شود.
📄 روی «پردازش» بزنید و چند دقیقه صبر کنید. صورت‌جلسه نهایی (خلاصه + تصمیمات + اقدامات) در پاپ‌آپ افزونه ظاهر می‌شود.
✏️ اگر متن جلسه نیاز به اصلاح دارد، دکمه اصلاح رونوشت را بزنید تا LLM متن را بازبینی کند.
